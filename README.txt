Техническая документация к лабораторной работе 2.3.1

1. Введение

Данная лабораторная работа посвящена разработке программы на языке C, которая обрабатывает последовательность целых чисел. Программа должна находить n-ое наибольшее и m-ое наименьшее число в последовательности (с учетом уникальных значений), а затем вычислять среднее арифметическое и стандартное отклонение подпоследовательности, расположенной между найденными числами.

2. Описание задачи

Программа должна выполнять следующие действия:

1.  Ввод данных:
    *   Считать с консоли два целых числа: n и m, представляющие порядковые номера наибольшего и наименьшего чисел, которые необходимо найти.
    *   Считать с консоли последовательность целых неотрицательных чисел, каждое на новой строке. Последовательность завершается числом -1, которое не входит в саму последовательность.
2.  Обработка данных:
    *   Сохранить введенную последовательность чисел в динамически выделенной памяти.
    *   Найти n-ое наибольшее и m-ое наименьшее число в последовательности, принимая во внимание только уникальные значения.  Если в последовательности есть повторяющиеся числа, они должны учитываться только один раз при определении n-го наибольшего и m-го наименьшего.
    *   Определить подпоследовательность чисел, расположенную между m-ым наименьшим и n-ым наибольшим числами (включительно) в порядке их появления в исходной последовательности. Если m-ое наименьшее число встречается в последовательности раньше n-го наибольшего, подпоследовательность начинается с m-го наименьшего. В противном случае, подпоследовательность начинается с n-го наибольшего и заканчивается m-ым наименьшим.
    *   Вычислить среднее арифметическое и стандартное отклонение для чисел в полученной подпоследовательности.
3.  Вывод данных:
    *   Вывести на консоль n-ое наибольшее и m-ое наименьшее числа, разделенные пробелом.
    *   Вывести на консоль среднее арифметическое и стандартное отклонение подпоследовательности, разделенные пробелом. Среднее и стандартное отклонение должны быть выведены с точностью до одного знака после запятой.

3. Архитектура программы

Программа состоит из следующих модулей:

•   main.c:  Основной модуль, содержащий функцию main(). Отвечает за ввод данных, вызов функций обработки данных и вывод результатов.
•   sequence.h / sequence.c:  Модуль, реализующий структуру данных для хранения последовательности чисел с динамическим выделением памяти.  Предоставляет функции для инициализации, добавления элементов, освобождения памяти, сортировки, а также для поиска n-го наибольшего и m-го наименьшего чисел.  Содержит структуру Sequence, которая включает указатель на массив целых чисел (data), текущий размер массива (size) и выделенную емкость (capacity).
•   stats.h / stats.c:  Модуль, содержащий функции для вычисления среднего арифметического и стандартного отклонения последовательности чисел.

4. Описание модулей

•   main.c:
    *   Функция main():
        *   Считывает значения n и m.
        *   Инициализирует структуру Sequence.
        *   Считывает последовательность чисел и добавляет их в структуру Sequence.
        *   Вызывает функции sequence_find_nth_largest и sequence_find_mth_smallest для нахождения соответствующих чисел.
        *   Определяет индексы найденных чисел в исходной последовательности.
        *   Извлекает подпоследовательность между найденными индексами.
        *   Вызывает функции calculate_mean и calculate_standard_deviation для вычисления статистических характеристик подпоследовательности 


    *   **`sequence.h` / `sequence.c`:**
        *   Структура `Sequence`:  Описывает структуру данных для хранения последовательности чисел.
        *   `sequence_init(Sequence *seq)`: Инициализирует структуру `Sequence`, выделяя начальный объем памяти для хранения чисел.
        *   `sequence_append(Sequence *seq, int value)`: Добавляет новый элемент в последовательность. Если текущая емкость массива заполнена, увеличивает ее вдвое.
        *   `sequence_free(Sequence *seq)`: Освобождает память, выделенную для хранения последовательности.
        *   `sequence_get(const Sequence *seq, size_t index)`:  Возвращает элемент последовательности по указанному индексу.
        *   `sequence_sort(Sequence *seq)`: Сортирует последовательность чисел в порядке возрастания (используется алгоритм "пузырьковой" сортировки).
        *   `sequence_find_nth_largest(const Sequence *seq, int n)`: Находит n-ое наибольшее число в последовательности.
        *   `sequence_find_mth_smallest(const Sequence *seq, int m)`: Находит m-ое наименьшее число в последовательности.
    *   **`stats.h` / `stats.c`:**
        *   `calculate_mean(const int *data, size_t start, size_t end)`: Вычисляет среднее арифметическое подпоследовательности чисел от индекса `start` до индекса `end` (включительно).
        *   `calculate_standard_deviation(const int *data, size_t start, size_t end, double mean)`: Вычисляет стандартное отклонение подпоследовательности чисел от индекса `start` до индекса `end` (включительно), используя предварительно вычисленное среднее арифметическое `mean`.

**5. Используемые структуры данных**

*   **`Sequence`:**  Структура для хранения последовательности чисел (описана выше).

**6. Алгоритмы**

*   **Сортировка:**  Для сортировки последовательности чисел используется алгоритм "пузырьковой" сортировки.
*   **Поиск n-го наибольшего/m-го наименьшего:**
    1.  Создается копия исходной последовательности.
    2.  Копия последовательности сортируется.
    3.  Создается массив уникальных значений из отсортированной копии.
    4.  Выбирается n-ое наибольшее или m-ое наименьшее значение из массива уникальных значений.
*   **Вычисление среднего арифметического:**  Суммируются все числа в подпоследовательности и делятся на количество чисел в подпоследовательности.
*   **Вычисление стандартного отклонения:**  Для каждого числа в подпоследовательности вычисляется квадрат разности между числом и средним арифметическим.  Суммируются все квадраты разностей, делятся на количество чисел в подпоследовательности, и извлекается квадратный корень из результата.
